2. SETELAN WAJIB BATERAI PONSEL (AGAR GPS TIDAK MATI SENDIRI)

Penting disetel di tanah air agar saat di Arafah & Mina, pelacakan darurat tidak tertutup sepihak oleh sistem ponsel:

Merek Ponsel Langkah Pengaturan Mulai Otomatis & Daya
Xiaomi / Redmi / POCO 1. Buka Pengaturan -> Aplikasi -> Kelola Aplikasi -> Panduan Haji 2027.
2. Aktifkan "Mulai Otomatis" (Auto-start).
3. Pada menu Penghemat Baterai, pilih "Tidak Ada Pembatasan" (No Restrictions).
4. Buka Recent Apps (tombol kotak), tahan aplikasi lalu ketuk ikon GEMBOK.
Samsung (Galaxy) 1. Buka Pengaturan -> Perawatan Perangkat -> Baterai.
2. Pilih Batas Penggunaan Latar Belakang.
3. Pilih "Aplikasi yang tidak pernah tidur" -> Tambahkan Panduan Haji 2027.
OPPO / Realme 1. Buka Pengaturan -> Manajemen Aplikasi -> Panduan Haji 2027.
2. Izinkan "Mulai Otomatis" (Auto-launch).
3. Izinkan "Aktivitas Latar Belakang Penuh" tanpa batas daya.
Vivo / iQOO 1. Buka Pengaturan -> Baterai -> Konsumsi Daya Latar Belakang Tinggi.
2. Cari Panduan Haji 2027 -> Pilih "Izinkan Penggunaan Daya Latar Belakang".
3. Aktifkan Izin "Mulai Otomatis" di menu Pengelola Izin.

SISI BELAKANG
3. CARA MENANDAI TEMPAT (TENDA MINA / PINTU MASJID / HOTEL)
Kapan Dilakukan: Segera saat jemaah pertama kali tiba di lokasi (berdiri di area terbuka yang menghadap langit).
1. Buka aplikasi, ketuk tombol biru besar di tengah: [ TEMPAT SAYA ].
2. Ketuk tombol [ + TANDAI TEMPAT INI ].
3. Tunggu 3 detik saat GPS menstabilkan akurasi (mengambil 5 sampel terbaik).
4. Ketik nama tempat (contoh: "Tenda Maktab 42 Mina") lalu ketuk [ SIMPAN ].
4. CARA MENEMUKAN ARAH PULANG DENGAN KOMPAS PANAH
Membaca Panah Hijau 1. Buka menu [ TEMPAT SAYA ] -> Pilih nama tempat tersimpan.
2. Pegang ponsel mendatar setinggi dada sejajar tanah.
3. Putar tubuh Anda sampai ujung panah menunjuk lurus ke depan. Ikuti arah panah tersebut.
Arti Lampu Sinyal Akurasi • HIJAU: GPS sangat akurat (≤ 10 meter).
• KUNING: Akurasi sedang (11–30 meter).
• MERAH: Sinyal GPS lemah / jemaah di dalam gedung beton/basement.
BILA PANAH BERPUTAR LIAR (GANGGUAN MAGNET TIANG BAJA): Jangan panik! Ayunkan ponsel Anda membentuk gerakan angka 8 di udara sebanyak 2 hingga 3 kali. Sensor kompas akan otomatis terkalibrasi normal kembali.
5. CARA MENGHUBUNGKAN PELACAKAN KELUARGA (QR 5 MENIT)
Jemaah Lansia (Yang Dilacak) Pendamping / Anak / Ketua Regu (Pelacak)
1. Buka menu [ KELUARGA ].
2. Ketuk tombol [ BAGIKAN LOKASI SAYA ].
3. Muncul kode QR acak dengan hitung mundur 5:00 menit.
4. Tunjukkan kode QR ke layar HP pendamping. 		1. Buka menu [ KELUARGA ].
2. Ketuk tombol [ PINDAI KODE QR ].
3. Arahkan kamera HP ke kode QR di layar jemaah lansia.
4. Status langsung TERHUBUNG dan posisi terpantau.
PENCABUTAN IZIN & HAPUS TOTAL DATA (RIGHT TO BE FORGOTTEN):
• Jemaah dapat mencabut izin kapan saja dengan mengetuk [ CABUT IZIN ].
• Setelah selesai haji, buka [ PENGATURAN ] -> [ HAPUS SELURUH DATA SAYA ] untuk menghapus bersih 100% data lokasi dari server dan memori ponsel (Sesuai UU PDP No. 27/2022).
